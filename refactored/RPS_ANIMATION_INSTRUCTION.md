# Инструкция по настройке анимации для мини-игры "Камень-Ножницы-Бумага"

## Что было сделано:

### 1. Созданы новые файлы:

#### Скрипты:
- `res://scripts/rps_animation.gd` - управляет проигрыванием OGV анимации
- `res://scripts/rps_result_window.gd` - окно с результатом (победа/поражение/ничья)
- `res://scripts/rps_window.gd` - обновлено для поддержки анимации и окна результата

#### Сцены:
- `res://scenes/ui/rps_animation.tscn` - сцена для проигрывания видео
- `res://scenes/ui/rps_result_window.tscn` - сцена окна результата

#### Папка для анимаций:
- `res://animations/rps/` - сюда нужно положить OGV файлы анимаций

---

## Как это работает:

### Поток игры:
1. Игрок входит в контакт с EnemyRPS
2. Открывается окно выбора (Камень/Ножницы/Бумага)
3. Игрок выбирает вариант
4. **Генерируется выбор врага** (случайно)
5. Окно выбора скрывается
6. **Проигрывается анимация** (OGV видео)
7. После анимации показывается окно результата
8. Игрок нажимает "OK"
9. Все окна закрываются, игрок становится видимым, игра продолжается

---

## Как создать анимации:

### Формат имен файлов:
Анимации должны называться по шаблону: `<выбор_игрока>_<выбор_врага>.ogv`

Возможные варианты (9 комбинаций):
- `rock_rock.ogv` - игрок: камень, враг: камень (ничья)
- `rock_scissors.ogv` - игрок: камень, враг: ножницы (победа)
- `rock_paper.ogv` - игрок: камень, враг: бумага (поражение)
- `scissors_rock.ogv` - игрок: ножницы, враг: камень (поражение)
- `scissors_scissors.ogv` - игрок: ножницы, враг: ножницы (ничья)
- `scissors_paper.ogv` - игрок: ножницы, враг: бумага (победа)
- `paper_rock.ogv` - игрок: бумага, враг: камень (победа)
- `paper_scissors.ogv` - игрок: бумага, враг: ножницы (поражение)
- `paper_paper.ogv` - игрок: бумага, враг: бумага (ничья)

### Куда положить файлы:
Поместите все 9 OGV файлов в папку:
```
res://animations/rps/
```

### Требования к видео:
- Формат: **OGV** (Ogg Video)
- Godot должен иметь возможность импортировать этот формат
- Рекомендуется разрешение: 1920x1080 или пропорционально меньше
- Длительность: 2-5 секунд (на ваше усмотрение)

---

## Как создать OGV файл:

### Вариант 1: Конвертация из другого формата
Если у вас есть видео в другом формате (MP4, AVI, etc.):
```bash
ffmpeg -i input.mp4 -c:v libtheora -qscale:v 7 -c:v libvorbis -qscale:a 5 output.ogv
```

### Вариант 2: Экспорт из видеоредактора
Некоторые видеоредакторы поддерживают экспорт в OGV напрямую.

### Вариант 3: Использование WebM вместо OGV
Godot также поддерживает WebM (.webm), что может быть проще:
- Измените в скрипте `rps_animation.gd` расширение с `.ogv` на `.webm`
- Создавайте файлы в формате WebM

---

## Настройка в Godot:

### 1. Проверьте импорт видео:
- Убедитесь, что Godot корректно импортирует OGV файлы
- В панели Import проверьте настройки для видеофайлов

### 2. Если OGV не работает:
Godot может иметь проблемы с OGV в некоторых версиях. Альтернативы:

#### A. Использовать WebM:
В файле `res://scripts/rps_animation.gd` измените строку:
```gdscript
return "%s_%s.ogv" % [player_name, enemy_name]
```
на:
```gdscript
return "%s_%s.webm" % [player_name, enemy_name]
```

#### B. Использовать AnimationPlayer с спрайтами:
Вместо видео можно использовать обычную анимацию Godot:
- Создайте сцену с AnimationPlayer
- Добавьте спрайты для игрока и врага
- Анимируйте их движение навстречу друг другу
- Это может быть даже проще чем видео!

---

## Тестирование без анимаций:

Система будет работать даже если анимации еще нет:
- Если файл анимации не найден, система подождет 1 секунду и покажет результат
- Это позволяет тестировать логику пока вы создаете анимации

1. **Создайте одну тестовую анимацию** (например `rock_scissors.ogv`)
2. **Положите в `res://animations/rps/`**
3. **Запустите игру и протестируйте**
4. **Создайте остальные 8 анимаций**

---

## Если что-то не работает:

### Проверьте консоль:
Система выводит подробные логи:
- `[RPSWindow]` - события окна выбора
- `[RPSAnimation]` - события анимации
- `[RPSResultWindow]` - события окна результата

### Частые проблемы:
1. **Видео не проигрывается** - проверьте формат файла и путь
2. **Окно результата не появляется** - проверьте подключение сигналов
3. **Игра не возобновляется** - убедитесь что нажали OK в окне результата

---

## Упрощенная альтернатива (без видео):

Если видео слишком сложно, можно использовать простую анимацию через Godot:

1. Создайте сцену с двумя Sprite2D (игрок и враг)
2. Добавьте AnimationPlayer
3. Создайте анимацию движения друг к другу
4. Меняйте текстуры спрайтов в зависимости от выбора

Это может быть даже проще и надежнее чем видео!
